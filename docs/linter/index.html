7 个检测信号（自动过滤测试/锁文件/非代码文件） 7 Detection Signals (Auto-Skips Tests, Lockfiles & Docs)

不必要的文档字符串Unnecessary Docstrings

检测为已有函数补加的 docstring / JSDoc 块，或超长注水文档（>12 行/函数）。Docstring/JSDoc blocks added to existing functions, or bloated docs (>12 lines/func).

过度错误处理Excessive Error Handling

新增业务代码中 try/catch/except/raise 占比超过 25%（自动跳过测试文件）。>25% of added non-test code lines are try/catch/except/raise.

未请求的新文件New Files Created

新建超过 15 行的非测试代码文件，可能超出需求范围。New non-test code files (>15 lines) that may exceed the requested scope.

类型检查膨胀Type-Check Bloat

新增 3 处以上运行时 isinstance / typeof / Array.isArray 检查（忽略注释）。3+ runtime isinstance / typeof / Array.isArray checks added (comments ignored).

不必要的抽象Unnecessary Abstractions

投机性设计模式声明（Factory、Strategy、Builder 等）或单文件新增 3+ class/interface（不误报普通 TS type 别名）。Speculative pattern classes (Factory, Strategy, Builder, etc.) or 3+ classes/interfaces in one file (ordinary TS type aliases ignored).

整文件重写Whole-File Rewrite

对已有文件在单个大 hunk 中对称增删 35+ 行（捕获 AI "改一行重写全文件" 模式）。Existing file with >=35 symmetric lines added/removed in one hunk (catches full-file rewrites).

范围蔓延Scope Creep

非锁文件改动数量超限（默认 8 个），或简短标题 PR 改动超 5 个文件。Non-lockfile changes exceeding maxFiles (default 8), or short PR title touching >5 files.
